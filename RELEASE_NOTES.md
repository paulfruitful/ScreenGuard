# Screen Guard v1.0.0 — Release Notes

**Browse Safe. Live Free.**  
*Release Date: November 24, 2026 | Platform: Android 11–16*

---

## Overview

Screen Guard v1.0.0 delivers a faster, stricter, and more reliable system-wide content protection experience. Explicit imagery and video across social media, web browsers, and third-party applications are covered automatically with a clean protective shield, while all inspection stays 100% private on your device.

---

## Highlights

### Strict-Only Protection
- Removed **Balanced mode** and the **Dismiss for This Screen** option so protection remains firm and consistent whenever explicit content appears.
- Automatic fade-out recovery removes the shield smoothly once you return to safe content.

### Faster Detection Across Social Media
- Upgraded frame inspection for **X (Twitter)**, **Instagram**, **TikTok**, **Chrome**, **YouTube**, and **Facebook** so in-feed videos and posts are detected immediately without waiting on surrounding UI elements.
- Continuous, non-stalling frame checks keep up with scrolling feeds and auto-playing videos.

### Scripture Encouragement & Return to Safe Browsing
- Each time the protective shield appears, it displays a randomly selected Bible verse ministering against lust and temptation.
- Added a **Read Full Scripture in Bible** button to open the full passage directly in an installed Bible app or on `bible.com`.
- Tapping **Return to Safe Browsing** exits the offending screen and takes you straight to the **Screen Guard Home** page.

### Long-Running Reliability
- Promoted the Accessibility observer to a persistent foreground service to prevent background task killers on Android and Xiaomi HyperOS from stopping protection.
- Added clear Home screen guidance if system battery settings need to be adjusted.
- Redesigned Home, Activity, Capture, and Settings screens with a clean Royal Blue, Gold, and White interface.

---

## Privacy Guarantee

- **100% On-Device Processing:** Zero cloud uploads and zero external servers.
- **Zero Disk Retention:** Screen frames are inspected in temporary memory and discarded immediately.
- **Private Input Respect:** Password fields, banking apps, and private/incognito windows are never captured.
